# Data Structures & Algorithms (DSA) Portfolio

A professional collection of algorithmic implementations and a comprehensive management system developed during the **3rd Semester** of the Software Engineering program at Fatima Jinnah Women University.

---

## 🚀 Featured Project: Student Record Management System
This flagship project represents the practical application of complex data structures to solve real-world academic data management challenges.
*   **Architecture**: Built using a **Binary Search Tree (BST)** to ensure optimized hierarchical data organization.
*   **Efficiency**: Designed with **$O(\log n)$** time complexity for searching, insertion, and deletion operations.
*   **Key Features**:
    *   Dynamic student record management (Add, Delete, and Update functionalities).
    *   High-speed search functionality using unique Student IDs.
    *   Comprehensive academic reporting via Inorder, Preorder, and Postorder tree traversals.

## 📂 Learning Roadmap & Implementation Sequence
This repository is organized numerically to reflect a progressive learning journey, moving from fundamental linear structures to advanced non-linear systems:

### Phase 1: Linear Fundamentals
*   **1. Implementing Stack**: Focused on LIFO operations and practical applications like Infix to Postfix expression conversion.
*   **2. Implementing Queues**: Features both Linear and Circular Queue models to demonstrate efficient memory utilization.

### Phase 2: Linked List Evolution
*   **3. Singly Linked List**: The foundation of dynamic node allocation and unidirectional data traversal.
*   **4. Doubly Linked List**: Implementation of bidirectional navigation for enhanced data accessibility.
*   **5. Circular Linked List**: Creating continuous data loops where the tail node connects back to the head.
*   **6. Circular Doubly Linked List**: An advanced structure combining bidirectional links with a circular loop for complex navigation.

### Phase 3: Hierarchical Data Structures
*   **7. Binary Search Tree (BST)**: Detailed implementation of sorted, non-linear data storage, featuring recursive and iterative traversal logic.
